# Family Finance Bot

## Status

Project source of truth: `plan/`. All documents are approved by the project owner as of 2026-09-16.

## Product

Telegram-first, multi-workspace financial recording system for families and communities. PostgreSQL is the source of truth; Google Sheets is a reporting projection; PDF is generated by the backend.

## Core Rules

- A workspace is the tenant boundary. Every financial record must have `family_id` (the database name for a workspace).
- A Telegram chat maps to exactly one active workspace. A workspace can have multiple chats.
- Telegram user IDs identify users; never use phone numbers as identities.
- A user can belong to multiple workspaces. Private bot chat requires an active workspace context.
- Do not hard-delete financial transactions. Use `VOIDED` or a correcting transaction and audit every financial change.
- Wallet balances are reconstructed from `initial_balance + SUM(active ledger entries)`.
- A transfer is not family income or expense and must create equal, opposite ledger entries.
- Permission checks are mandatory for every wallet, transaction, report, PDF, and Sheets projection.
- Never trust Google Sheets or an LLM as financial source of truth.

## Delivery Order

1. Tenant/membership/group binding, wallets, ledger, audit, and Telegram commands.
2. Rule-based Indonesian parser, confirmation, search, edit, and undo.
3. Google Sheets and PDF.
4. DeepSeek fallback and web dashboard.
